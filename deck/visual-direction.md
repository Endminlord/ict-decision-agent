# Visual Direction

## 视觉论点（visual thesis）

**一份像技术白皮书一样的演示。** 白底、克制的深蓝主色、**单一琥珀强调色**；可信感靠**数字的排版权重**和**原生绘制的结构图**建立，不靠色块与图标堆叠。

理由：观众是技术评委 —— 他们信**数字**与**结构**，不信装饰。每页只留**一个焦点**：要么一组大数字，要么一张结构图，要么一张证据截图。留白是**节奏**，不是没填满。

## 设计令牌（Theme Lock v1）

| 角色 | 值 | 用途 |
|---|---|---|
| 底色 | `#FFFFFF` | 全篇背景 |
| 主色 | `#0F2A44` 深蓝 | 标题、结构图主节点、表头 |
| 强调色 | `#C77D0A` 琥珀 | **关键数字**、唯一强调（每页 ≤2 处） |
| 次级色 | `#5A6B7C` 灰蓝 | 正文、次要标注 |
| 分隔线 | `#D8DEE5` | 表格线、分组线 |
| 正例色 | `#1F7A5A` 深绿 | 「通过 / 命中 / 已实现」 |
| 负例色 | `#A33A2A` 砖红 | 「拒答 / 失败 / 边界」 |

**字体**：标题思源黑体 Bold · 正文思源黑体 Regular · 数字与代码 Consolas 等宽
**网格**：左右边距 0.6in · 上边距 0.5in · 标题基线距顶 0.5in · 页脚页码右下
**间距节奏**：块间距 0.3in · 行距 1.35 · 数字组内间距 0.5in

## 页面原型（archetypes）

1. **封面**：左对齐大字标题 + 一行副标 + 底部细线；**无背景图、无徽标**
2. **数字页**：2–3 个大数字横排（等宽、琥珀色），下方一句话解释
3. **结构图页**：原生形状绘制的架构/流程，占页面 ≥60%，配 2–3 行说明
4. **证据页**：左侧截图（细边框）+ 右侧抽取的关键行（等宽字体）
5. **表格页**：细线表格、无斑马纹、表头深蓝底白字
6. **清单页**：单列、行距 1.4、序号用等宽字体

## 三个可调档位（dials）

- **Variance 6/10**：结构图页与数据页架构明显不同；但页头、页码、字体、配色全局一致
- **Motion 1/10**：静态页，无动画（评审场景多为翻阅 PDF）
- **Density 4/10**：低-中密度；第 2/4/5 页低密度，第 8/9/11 页中密度

## 留白的用途（每一处都要有理由）

- 封面下半部留白 → 让标题「重」
- 数字页数字之间的空隙 → 让三个数字被分别读到
- 结构图页四周留白 → 让图本身成为唯一焦点
- 第 12 页（边界清单）底部留白 → 收尾不压迫

## 禁止项（forbidden patterns）

- 华为红 / 华为徽标（避免被误认为官方模板）
- 渐变、阴影、圆角卡片墙
- 每页相同的卡片网格或项目符号列表
- 小于 14pt 的中文正文
- 用整页截图承载关键信息（截图只作证据）
- 「感谢聆听」结尾页
- 编造无法核实的数字（所有数字取自材料包实测记录）
