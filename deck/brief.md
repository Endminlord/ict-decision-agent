# Brief

- **Topic**: 基于 ModelEngine Nexent 打造可进化决策智能体 —— 让每条决策依据都能回查原文出处
- **Audience**: 华为 ICT 大赛（中国创新赛）赛题 3 初赛技术评委；评委熟悉 AI 平台与工程实现，但对本项目零背景
- **Scenario**: 初赛技术评审。材料随作品提交，评委大概率**先翻 PPT**（或按其要求做 8–10 分钟讲解）；无现场答疑机会时，PPT 必须能独立读懂
- **Language**: 简体中文（技术术语保留英文原文，如 MCP / Skill / RAG / ONNX）
- **Purpose / decision / action**: 让评委在 10 分钟内确认三件事并给出技术分：① 智能体回答**每条依据都能回查原文**（不是检索后拼凑）② **本体三层已实现且可复跑**（规则层 + 推理层 + 模型判定层，不是设计稿）③ **换行业零改码**（已用第二次迁移实测证明，四项指标全 0 改动）
- **Duration and page count**: 12 页（讲解 8–10 分钟，含 1 页演示录屏）
- **Source material**: `ict-material-20261010/` 材料包 —— `01-开发设计文档.md`（技术方案 + 实测数字）· `02-Nexent平台智能体设计说明.md`（平台侧 + 7 个示例问答）· `03-场景无关契约与迁移设计.md`（三层契约）· `240-ict-migration-mig002.md`（迁移实测）· `241-ict-gpu-embedding.md`（GPU 实测）· `evidence/`（8 张 UI 实拍 + 日志）· `figures/nexent-callgraph.png`（调用关系图）· `videos/`（2 段录屏）
- **Brand, image, data, and editability constraints**:
  - **无 VI 模板**：官方未提供模板，按自由设计（Build Mode），不使用华为商标/品牌色，避免误认为官方模板
  - **数据必须真实**：所有数字取自材料包实测记录，**不编造、不外推**；无法确认的（如初赛确切截止日）不写进页面
  - **可编辑**：正文用原生文本与形状（不用整页截图承载关键信息）；截图与录屏作为**证据**而非内容载体
  - **单人备赛须如实标注**：团队成员尚未确定，PPT 不虚构团队介绍页

## Outcome

评委看完应当：

1. **理解**：这是一个「可回查出处」的决策智能体 —— 跨层级政策链条（省级条例 → 国办函 → 市级决定）能一次答出，且每条带 `chunk_id`；证据不足时明确拒答而不是编造。
2. **记住三个数字**：**255,451** 条三元组（出处失败 0）· **15,870** 条文件→文件引用边 · 迁移改动 **0 / 0 / 0 行**。
3. **认可**：本体不是「设计稿」而是**三层都已实现、每条判据可复跑**；换行业只需换词表，代码零改动。
4. **行动**：给出技术分，并认为该项目具备进入总决赛的工程完整度。

## 讲故事的顺序（不是功能罗列）

**痛点 → 我们的答案 → 凭什么可信 → 怎么做到 → 换行业会怎样 → 边界**

具体：业务场景与痛点（政策依据分散）→ 智能体演示（可回查出处 + 拒答）→ 自建 MCP/Skill 的编排 → 本体三层（技术纵深）→ 零改码迁移（可迁移性）→ 诚实边界与下一步。
