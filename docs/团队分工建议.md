# 团队分工建议（3 人 + 1 指导教师）

> 这不是「我们做了什么」的记录，是**拿到报名表之后怎么填**的建议。当前三人各是谁尚未确定（`待补充清单.md` #1–4），所以下面按**职责**分，不按人名。

## 一、为什么现在就要定分工

赛题 3 的四项技术评分（各 15%）与答辩材料（20%）、评委问答（20%）是**分开打分**的。三个人如果都做技术，答辩时没人接得住「材料怎么组织的」；如果都做材料，技术纵深问不出来。**分工的目的是让每一块都有一个人能答到底**，不是把工作量三等分。

## 二、三个角色

### A · 检索与评测（技术纵深最硬的一块）

**负责**：`tools/cross-doc-demo.py`、`tools/eval-retrieval.py`、`evidence/eval-retrieval*.json`、`245-ict-retrieval-eval.md`

**必须能答**：
- 为什么 A 组 hit@1 只有 0.6，混合检索（BM25 / RRF）为什么更差（`245` §5 天花板实验）
- 领域外拒答 20/20 的余量有多薄（最高分 0.7466 距阈值 0.75 只有 0.0034）
- 词面判据被改写后的检索式自证是什么（`245` §4.4）

**答辩时的位置**：第 4–5 页（跨层级链条 / 拒答闸门）+ 第 11 页（能力沉淀）

### B · 本体与规则（叙事最容易讲错的一块）

**负责**：`ontology/`（`build.py` / `align.py` / `prune.py` / `judge.py`）、`236`/`238`/`239`/`240`/`241`、`evidence/ontology-*.json`

**必须能答**：
- 为什么是「规则层召回 → 模型层判定 → 人工闸门」三层，而不是直接上 LLM（`242` §3）
- 全量判定推翻抽样结论那件事：抽样池与全量分母为什么不可直接比（`答辩稿.md` Q3）
- `level_of()` 把层级硬编码成中文关键词，为什么英文语料的 D 组要标 N/A 而不是 0/15（`249` §12.3）

**答辩时的位置**：第 7–9 页（本体三层 / 规则层与推理层 / 模型判定层）

### C · 平台与工程（唯一能现场救场的一块）

**负责**：Nexent 平台（`02`）、`tools/demo-preflight.sh`、`tools/demo-launch.sh`、`track2-mcp/`、`答辩当天流程.md`

**必须能答**：
- Nexent 在系统里到底做了什么、没做什么（`答辩稿.md` Q12）
- `nexent-minio` 掉网络时 UI 假绿 126 秒才报错，怎么一眼看出来（`演示预检与断网降级.md` §2）
- `verify_quote` 的第二轮对抗还有 16 条绕过，剩下的是哪几类机制限制（`演示问题卡.md` §6.4）

**答辩时的位置**：第 1–3 页（开场 / 问题 / 答案）+ 第 10 页（迁移）+ 现场演示的全部操作

## 三、指导教师

规则要求 1 名、同校。**能起作用的地方**（不是挂名）：
1. **答辩前的模拟问答**：请老师扮演评委问 3 个最不客气的问题（比如「你们这个跟直接问 ChatGPT 有什么区别」）
2. **材料的形式审查**：报名表、封面、格式要求这类硬性条款，学生容易漏
3. **行业数据的授权渠道**：`待补充清单.md` #23（可授权的行业数据）如果有企业合作渠道，只有老师能推

## 五、如果只有一个人

那就一个人讲满 15 分钟，**但要主动说出来**：「这个规模三个人做更合理，目前是我一个人完成的，所以我在每一块都只能做到可验证的最小闭环。」—— 评委见过太多虚报团队规模的，主动说明比被问出来好。
