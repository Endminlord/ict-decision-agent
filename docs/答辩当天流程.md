## 三、90 秒仪式剧本（现场主秀）

```bash
cd ~/dsh/research/ict-open-source
python3 tools/verify-ritual.py full
```

旁白脚本（跟着四幕走）：

1. **第 1 幕**（~20s）："我们现场向生产系统提一个真实政策问题——注意回答带五条引用，每条有 chunk_id、时间、层级、分数。"
2. **第 2 幕**（~20s）："评委可以任指一条引用，我现场回查原文。ES 索引和 4.2GB 本地语料凭内容指纹互认，逐字一致——出处不是模型编的。"
3. **第 3 幕**（~20s）："知识库底下的本体图谱也有三重出处：规则证据、模型判定、语料源独立回查，全部现场实时。"
4. **第 4 幕**（~25s）："最后是 adversarial 环节：注入攻击被拒答护栏拦下、跨域问题九个来源不串台、时间演进不冒充最新——我们的系统虐不坏。"

**加演（评委起兴时）**：`python3 tools/verify-ritual.py adv`（对抗三连单独跑）
**信任面板**：浏览器开 `evidence/trust-panel.html`（U 盘/仓库双备份）

## 五、评委题库 TOP10（一句话答法）

1. **数字能复现吗** → `make all`：118 项测试 + 分层评测 + 四幕仪式一条命令全链重跑。
2. **拒答怎么判** → 稠密分数 0.75 护栏 + 词面落地核验双条件；域外题现场试（咖啡豆案例 0.93 分照样拒）。
3. **语料规模** → 政务语料 757,810 条 / 15.7 亿字符，全量 190 万块级导入中；制造业真实语料 22 篇/178 块已打通。
4. **检索为什么混合** → BGE-M3 稠密管语义、BM25 管词面，RRF 融合；消融对照：纯稠密漏拒答，混合后 M/X 双升。
5. **注入攻击怎么办** → 检索通道无指令跟随面 + 生成侧拒答护栏；对抗三连现场演示 0.92 高分注入仍被拦。
6. **为什么 RAG 不微调** → 决策依据必须可回查可更新，微调模型给不了 chunk 级出处；换行业只需换语料零改码。
7. **换行业真的零改码** → 政务→制造业已实测（MIG-002 四项指标全过），三层契约 L1/L2/L3。
8. **本体图谱怎么保证质量** → 三层漏斗 21 万→5,269 边 + review_gate 人工闸门，high 置信自动入库、其余复核。
9. **开源合规** → Apache-2.0；今晚刚把 PDF 通道从 AGPL 的 pymupdf 换成 MIT 的 pdfplumber——许可证卫生我们抠到了库级。
10. **满库复跑结论** → 20261030-1118：R hit@10 1.00 / MRR 0.8711，M 25/25，X 19/25，C/G 25/25；后续补延迟曲线、第二行业扩量至 1000+ 块。
