# 博客提纲：三层治理架构如何用 Nexent 实现

## 标题候选（3 个）

1. 《让智能体学会"守规矩"：基于 Nexent 的宪法层 / 可验证性域 / 免疫记录三层治理实践》

3. 《把判定权从模型手里拿出来：Nexent 智能体的三层治理落地笔记》

## 目标读者

- 正在用 Nexent / MCP 搭建行业智能体、关心"上线后如何可信可控"的开发者与架构师；
- 政务、制造等强合规场景的技术负责人，需要可回查、可审计、可回归的治理方案；
- 关注智能体工程化创新的评审与研究者（对应评分表中"算法创新性""MCP/Skill 深度集成"维度）。

## 核心论点（3 条）

1. **可信不是模型调出来的，是架构写死的**：把准入规则放进宪法层配置，而不是寄望提示词自觉，判定权外置后行为才可预期。
2. **每个结论都必须能被独立回查**：可验证性域让回答、引用、三元组都带出处，且核查走生产通路而非预录演示。
3. **系统进化要留下"免疫记录"**：每次变更可溯源、可回归、可证伪，配合统计门控，让能力提升是检验出来的而不是宣称的。

## 逐节提纲

### 一、引子：为什么"会答题"的智能体还不够（约 180 字）
- 用政务场景痛点开场：决策依据分散在海量文件里，智能体给出答案容易，给出"敢用的答案"难。
- 例证：docs/scoring-alignment-20261028.md 中"75.7 万条政务语料激活、决策溯源到块级（rings+chunk_id）"的资产事实。
- 引出主张：我们补上的是治理层，而不是再堆一个更大的模型。

### 二、总览：三层架构一张图（约 180 字）
- 简述三层分工：宪法层定"什么不许做"，可验证性域保证"说的都能查"，免疫记录回答"系统怎么变、变了有没有变好"。
- 例证：docs/scoring-alignment-20261028.md 第①③项的架构表述（宪法层+双命名空间、三层治理+免疫记录）。
- 说明三层都落在 Nexent 的 MCP/Skill 机制上，非外挂口号。

### 三、宪法层：把准入规则写死（约 260 字）
- 写什么：Skill 准入不靠提示词约定，而是配置层硬约束；区分 verified / observed 双命名空间，未验证能力不得进入可信通路。
- 例证：docs/scoring-alignment-20261028.md "宪法层（Skill 准入写死配置）+ Skill 分层编排（verified/observed 双命名空间）"；提交记录 c48110b 作为已落地证据。
- 点题：这是"判定权外置"的第一层——能不能做，由配置裁决，不由模型发挥。

### 四、可验证性域：让每句话都有出处（约 380 字）
- 写什么：回答—引用—原文三环回查设计；多跳检索合流时图环只是补充证据，词面落地闸门不变，宁可拒答也不硬答。
- 例证1：tools/verify-ritual.py 的四个子命令 ask / trace --deep / panel / full，90 秒仪式全部走生产 MCP（8793）+ 真实 ES。
- 例证2：同文件 deep_verify 的双通道对账——ES 通道与本地语料通道凭内容指纹认亲，"两条独立通道对上，才是真在库里"。
- 例证3：docs/design-graphrag-retrieval.md 的护栏数字——图分上限 0.9、grounded 词面闸不变、GRAPH_BOOST 可一键关闭。
- 点题：可验证不是 UI 装饰，是检索契约本身。

### 五、免疫记录：让进化可溯源、可回归（约 320 字）
- 写什么：变更留痕（OTel trace、版本历史、parent_skill_id 谱系），新能力上线前过统计门控与回归守卫，拒绝"看分数挺好就合并"。
- 例证：docs/scoring-alignment-20261028.md 的 D2/D3-4 路线图（免疫记录模块、Wilcoxon 逐项配对检验、n≥15 下限写死、冻结集回归）。
- 强调红线：统计门控只约束新的进化声明，不追溯既有数字；n=25 功效有限需如实标注。
- 点题：免疫系统不是不变，而是每次变都留证据。

### 六、实证：迁移与数据是最硬的证词（约 260 字）
- 写什么：治理架构不是演示道具，用真实数据与零改码迁移说话。
- 例证：docs/scoring-alignment-20261028.md 的附加分事实——22 篇 / 178 块 gov.cn 真实脱敏语料全链判据 PASS，政务→制造业 MIG-002 零改码迁移四指标。
- 收束：三层治理让"可信"从一次演示变成可重复、可迁移的工程属性。

### 七、结语与边界（约 120 字）
- 一句话回扣三论点：写死的规则、可回查的证据、可证伪的进化。
- 诚实标注边界：图谱噪声、样本量功效限制等已知风险（引 docs/design-graphrag-retrieval.md 风险表与 scoring 文档红线），可信架构不等于完美架构。
