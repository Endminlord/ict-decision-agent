# 复核命令（逐条可复跑）

**用途**：评审/队友按此清单可在同一台机器上复现本作品的全部结论。

**先做这一步（否则 `$M` 是空的，`cd $M` 会回到 HOME）**：

```bash
cd <材料包根目录>          # 例：cd ict-material-20261010
export M=$(pwd)           # 此后本文所有 $M 才有值
```

**约定**：`$M` = 本材料包目录（由上一步 `export` 定义）；命令均在本机实测过，实测结果写在「实测」列。
**写盘约定**：所有会产出文件的命令一律写 `/tmp/...`，**不要写回包内** —— 包内文件已入 `MANIFEST.sha256`，
写回会让 `sha256sum -c` 立刻报 FAILED（§H 会红）。包内的 `ontology/reason-report.json`、
`ontology/judged-400.jsonl`、`evidence/*.json` 都是**归档快照**，只读。
只读接口在本部署中**不要求登录 cookie**（mock 身份）；写接口（安装/注册/更新）曾带 cookie 调用。
