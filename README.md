# 可进化决策智能体 · 材料包

> **赛题**：第十一届华为 ICT 大赛 · 中国创新赛 · **赛题 3**（基于 ModelEngine Nexent 打造可进化决策智能体）
> **材料版本**：`ict-material-20261010` · 最后更新 **2026-10-17** · 完整性与校验见 `MANIFEST.sha256`

---

## 0. 一句话

在 **Nexent 平台**上自建 **2 套 MCP 服务**（6 个工具）与 **2 个 Skill**，把 **4.18 GB 政务公开语料**（757,810 条 / 15.7 亿字符）做成**每条结论都能回查原文出处**的决策依据链；
并为「换行业」给出**三层契约**与**已实测的零改码迁移**（政务 → 先进制造）。

**它解决什么问题**：政务/行业决策的依据分散在成千上万份文件里，人工梳理「谁引用了谁」成本极高。本作品让智能体回答业务问题时**逐条给出可回查的原文出处**，并在证据不足时**明确拒答**而不是编造。

1. **双侧过滤**：subject 与 object 都判为真文件后，得 **15,870 条**文件→文件引用边（8,532 节点），文件图 1,661 节点 / 9,167 边 / 最大深度 3 跳。

2. **官方参数未确认**：初赛确切截止日、晋级名额、是否强制华为技术栈、是否需 PPT/演示视频、是否需开源仓库等（#5–#10、#20、#23）。
3. **语料是政务公开数据**，不等于「企业内部沉睡数据资产」；本作品表述为「**政务公开数据资产的激活路径**」。
4. **先进制造语料通道已断链**（#25/#28）：国标全文受版权、gov.cn 政策 API 匿名 0 结果、ModelScope 文档型工业语料 403。因此 MIG-002 迁移实测用的是**合成语料**，验证的是**机制**而非真实行业效果。
5. **本体判定层用的是自备网关的外部模型**（非本地模型），换模型结论可能变；`review_gate` 之后**仍无一条人工确认入库**。
6. **GPU 化已落地**（2026-10-17 09:34）：`bge-m3-embed` 切 CUDA 后 **387 条/秒**（CPU 14.4 ⇒ 26.9×），双侧评测读数逐项零退化；演示用 batch ≤ 16（batch=32 抖动大）。
7. **示例 7 的原始长问题复现不稳定**：两次重拍均失败（一次停在 25% 无最终答案、一次模型返回空响应），失败快照一并留档在 `evidence/15b-*`；材料中使用的是同技能的**简化提问**版本。
8. **知识库全量导入要占满写入窗口**：1,864,451 块按 batch 200 实测 **35.57 块/秒 ≈ 14.6 小时**（CPU 时代 0.8 块/秒 ≈ 27 天，见 `241-ict-gpu-embedding.md` §5），期间写入通道被占满，故采用「主题关键词 + 分层抽样」的 15,000 块子集策略。
9. **效果评测只覆盖已入库的 0.83% 子集**（15,494 / 1,864,451 块，块数以 ES `_count` 为准）；评测**未做人工标注**，因此没有传统意义上的准确率/召回率——评的是「可验证性」与「拒答行为」这两项能客观测量的能力。
10. **决赛材料未经过实战检验**：答辩稿未试讲（`tools/rehearsal-timer.py` 已备，12 页时间码合计 900 秒，可逐页量偏差）、华为云算力未申请（无账号）、赛题 2 的 AgentArts 公测审核未通过（平台侧四项交付全阻塞）。
11. **中文提问在英文语料上的跨语言拒答问题已修（2026-10-17）**：修复前 5/5 全拒——向量召回本身是对的（`max_score` 0.818–0.852，**全部高于 0.75 阈值**），但拒答判据含**词面落地**检查，汉字在英文正文里命中数为 0 ⇒ 判为证据不足。修法**不是删掉词面判据**（领域外拒答靠它拦住：RFC 侧有 1 题 `max_score = 0.7600` 越过了 0.75，单靠向量阈值会漏拒），而是**跨语言时改走单条更严的分数门 0.80**——修复后 RFC 领域内答出 **10/15 → 15/15**，领域外拒答仍 **20/20**。同轮还修了「公文引号切开缩略词」导致的中文误拒（政务 9/10 → **10/10**）。数据与取舍见 `249-ict-track2-verify-experiment.md` §12。
12. **RFC 语料的「跨文档链」指标不适用**：`level_of` 把「国家 / 地方 / 媒体」三层**硬编码成中文关键词**，英文语料上三条规则全部不命中 ⇒ 每块都落进兜底值「媒体」⇒ `level_span` 恒为 0。**层级概念本身是领域特定的**（RFC 文档之间没有政务那种行政层级）⇒ **2026-10-17 已标 `not_applicable: true`**：`level_of` 对 `RFC \d+` 返回「未知」，评测层检测到全未知就报 N/A 而不是 0/15。见 249 §12.3。
